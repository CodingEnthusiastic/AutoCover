\begin{abstract}
Vehicle insurance comparison in fragmented markets requires motorists to navigate multiple opaque portals, repeatedly re-enter regulatory specifications, and decipher incompatible marketing terminology. This technical report presents \textbf{AutoCover}, an end-to-end car insurance aggregation platform built with \textbf{React 18}, \textbf{TypeScript}, \textbf{Python 3.12}, \textbf{FastAPI}, and \textbf{SQLAlchemy}. AutoCover ingests raw quote data from four heterogeneous sources (JSON REST API, JavaScript-hydrated HTML DOM, India Motor Tariff rate card PDF, and CSV exports), handles duplicate and malformed records, normalizes add-on terminology based on empirical research across four leading Indian insurers (Acko, HDFC ERGO, Digit, ICICI Lombard), isolates latency and service failures via non-blocking asynchronous aggregation, computes multi-dimensional value scores, and delivers policy lifecycle tracking with automated renewal reminders.
\end{abstract}

\section{Executive Summary}

AutoCover solves the friction of car insurance discovery through an intuitive, customer-centric architecture:
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Single-Entry Lookup:} The user enters their vehicle registration number once. The system standardizes casing, spacing, and punctuation, retrieves verified specifications from the vehicle registry, and enables manual overrides if registered records differ from the registration certificate (RC).
    \item \textbf{Concurrent Multi-Provider Ingestion:} Queries four distinct simulated provider services concurrently. Handles a intentionally slow provider (Provider B, $\sim$1.5s simulated latency) and an intermittently failing provider (Provider D, HTTP 503 simulation) without blocking other providers.
    \item \textbf{Data Normalization \& Rate Modeling:} Standardizes diverse pricing schemas (tax-inclusive vs net base + 18\% GST), parses hydrated script states from HTML, executes dynamic underwriting tariff calculations from PDF rate cards, and cleans malformed CSV exports.
    \item \textbf{Transparent Value Scoring:} Implements a multi-factor recommendation algorithm (0--100) scoring IDV protection efficiency, bundled add-on depth, and active validity, assigning \textit{Best Value}, \textit{Lowest Price}, and \textit{Maximum Coverage} badges.
    \item \textbf{Policy Management \& Expiry Reminders:} Persists mock policy selections and proactively flags policies approaching expiration within 15 days, providing simulated WhatsApp/SMS renewal alerts.
\end{enumerate}

\section{High-Level System Architecture}

\subsection{Architecture Overview}
The platform employs a decoupled micro-service layout:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Frontend Application:} React 18, TypeScript, Tailwind CSS, Lucide icons, and Vite.
    \item \textbf{Backend REST API:} Python 3.12, FastAPI, Pydantic V2, and Uvicorn.
    \item \textbf{Persistence Layer:} SQLAlchemy ORM with SQLite for zero-dependency local execution and native PostgreSQL support via environment variable configuration.
    \item \textbf{Provider Simulation Suite:} Dedicated endpoints serving JSON, HTML, PDF, and CSV payloads with latency and fault-injection controls.
\end{itemize}

\section{Heterogeneous Data Ingestion \& Normalization}

\subsection{Provider A: REST API (JSON)}
\begin{itemize}[leftmargin=1.2em]
    \item \textbf{Source:} \texttt{provider\_a.json}
    \item \textbf{Deduplication:} Duplicate quotes (e.g. quote indices 1 and 2 for \texttt{WB02AB1234 Comprehensive Plus}) are identified by composite key: \texttt{(plan, coverage, idv, premium, addons)}.
    \item \textbf{Tax Isolation:} Some quotes specify \texttt{base\_premium} with a tax structure, while others specify \texttt{premium} with \texttt{premium\_includes\_gst: true}. Both are normalized into base premium and 18\% GST.
    \item \textbf{Quote Validity:} Assessed against the reference date (\texttt{2026-11-10}). Quotes for \texttt{KL07DE3030} valid until \texttt{2026-11-05} are flagged as \texttt{EXPIRED}.
    \item \textbf{Underwriting Declines:} Quotes with \texttt{status: "DECLINED"} (e.g. \texttt{WB06CD5678} due to age $>10$ years) are preserved and surfaced with explicit reasons.
\end{itemize}

\subsection{Provider B: Webpage with JS Hydration (HTML)}
\begin{itemize}[leftmargin=1.2em]
    \item \textbf{Source:} \texttt{provider\_b.html}
    \item \textbf{DOM vs Script State:} Plan titles and add-on lists are in static HTML, but prices and cover amounts are dynamically hydrated from an inline script:
    \begin{lstlisting}[language=javascript]
    window.__QUOTE_DATA__ = {
      "B-101": {"total": "INR 12,830", "cover": "3.1 L", "valid_till": "30-11-2026"}
    };
    \end{lstlisting}
    \item \textbf{Data Extraction:} Uses regular expressions to extract the JSON dictionary and \texttt{BeautifulSoup} to parse DOM cards.
    \item \textbf{IDV Conversion:} Strings like \texttt{"3.1 L"} or \texttt{"12.5 L"} are converted to integer Rupee values ($310,000$ and $1,250,000$).
    \item \textbf{Latency Simulation:} A sleep delay of 1.5 seconds is injected to replicate an external slow provider.
\end{itemize}

\subsection{Provider C: Rate Card Tariff (PDF)}
\begin{itemize}[leftmargin=1.2em]
    \item \textbf{Source:} \texttt{provider\_c.pdf}
    \item \textbf{Underwriting Engine:} Rather than returning static quotes, Provider C defines a complete mathematical tariff following the \textbf{India Motor Tariff}:
    \begin{equation}
    \text{IDV} = \text{Ex-Showroom Price} \times (1 - \text{Depreciation}(\text{Age}))
    \end{equation}
    \item \textbf{Depreciation Tiers:} $\le 6$ months: 5\%; 6m--1y: 15\%; 1--2y: 20\%; 2--3y: 30\%; 3--4y: 40\%; 4--5y: 50\%; 5--8y: $50\% + 5\% \times (\text{years} - 5)$; $>8$ years: \textbf{Declined}.
    \item \textbf{Model Grouping:} Group 1 (Swift, i20, Baleno, Alto K10, Tiago), Group 2 (Nexon, City, Sonet), Group 3 (Creta, XUV700, Innova Crysta).
    \item \textbf{OD \& TP Premiums:} Own Damage rate applied to IDV, discounted by No Claim Bonus (NCB). Third Party rate determined by cubic capacity ($\le 1000$cc: ₹2,094; $1000$--$1500$cc: ₹3,416; $>1500$cc: ₹7,897).
    \item \textbf{Eligibility Rules:} \texttt{C-Standard} is available up to 8 years. \texttt{C-Shield} (Nil Dep + RSA + Consumables) is restricted to vehicles $\le 5$ years.
\end{itemize}

\subsection{Provider D: Quote Export (CSV) \& Fault Injection}
\begin{itemize}[leftmargin=1.2em]
    \item \textbf{Source:} \texttt{provider\_d.csv}
    \item \textbf{Dirty Data Cleaning:} Strips comma formatting from currency strings (\texttt{"11,670"} $\to 11670.0$), normalizes mixed IDV representations (\texttt{"3.3 lakh"} vs \texttt{332000}), and deduplicates duplicate rows (\texttt{KL 07 DE 3030 Gold} plan repeated).
    \item \textbf{Fault Tolerance:} Implements an on-demand and stochastic 503 Service Unavailable simulation. The aggregator isolates the failure, allowing the remaining providers to display without interruption, while surfacing a 1-click retry action.
\end{itemize}

\section{Value Scoring \& Plan Recommendation}

Rather than assuming the cheapest plan is best, AutoCover calculates a 0--100 composite score:
\begin{equation}
\text{Score} = S_{\text{price}} + S_{\text{idv}} + S_{\text{addons}} + S_{\text{validity}}
\end{equation}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Price Affordability ($S_{\text{price}} \in [0, 35]$):} Evaluated as $35 \times \left(1 - \frac{P - P_{\min}}{P_{\max} - P_{\min}}\right)$.
    \item \textbf{IDV Protection ($S_{\text{idv}} \in [0, 30]$):} Evaluated as $30 \times \left(\frac{\text{IDV} - \text{IDV}_{\min}}{\text{IDV}_{\max} - \text{IDV}_{\min}}\right)$.
    \item \textbf{Add-on Coverage Depth ($S_{\text{addons}} \in [0, 30]$):} Weighted credit: Zero Dep (+12 pts), Engine Protect (+7 pts), RSA (+5 pts), Return to Invoice (+4 pts), Consumables (+2 pts).
    \item \textbf{Validity Bonus ($S_{\text{validity}} = 5$):} Granted to active quotes.
\end{itemize}
